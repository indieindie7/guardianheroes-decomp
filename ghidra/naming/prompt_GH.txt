Sega Saturn game Guardian Heroes (Treasure, European release MK-81035 V1.000, 1996-04-23; SH-2 code, SGL/SBL library calls likely). Research only. Game: 2D beat-em-up / fighting game with sprites on 3 depth planes (lane switching), RPG stats and levelling (experience, stat points spent on Strength/Vitality/Magic etc.), branching story with stage-select routes, Karma (alignment) that changes the path, magic spells and summons, a Versus mode with up to 45 characters and 6-player battles, Zombie Han, Undead Hero. Heroes: Han, Randy, Nicole, Ginjirou, Serena; bosses/enemies such as Gold Knight, Silver Knight, Dragon, Kanon, Zur. Files: per-character BIN/TNE/SEQ (HAN.BIN, HAN.TNE, HAN.SEQ: sprite data, tile/animation tables, sound sequences), stage ST<nn><n>.BIN code+data overlays and S<nn><n>CHR.BIN graphics, BG_xxx.BIN backgrounds, endings ENDn_D.BIN, SND.DRV 68000 sound driver, OPEN.CPK opening movie. Main program 0KRNL.BIN is loaded at 0x06004000 (kernel: mode dispatch, loader, shared routines; game-mode overlays GAME.BIN, VS.BIN, TVS.BIN, VSTART.BIN, TITLE.BIN, OPTION.BIN and per-stage ST*.BIN not imported). Focus names on the main loop and mode dispatch, file loader (GFS/CD), pad input and buffer, sprite and animation sequence playback, hit detection and damage, stat/level-up and Karma, AI, VDP1 sprite command output, VDP2 scroll backgrounds, menus, sound commands.

Task: name functions from the Ghidra decompile. FILE holds the decompile of a slice of the functions of 0KRNL.BIN. Name EVERY function in FILE whose name is still FUN_xxxxxxxx (skip ones that already have a name).

Evidence to use: strings, called functions (names given by earlier slices), Saturn hardware registers, how the function uses its arguments.
